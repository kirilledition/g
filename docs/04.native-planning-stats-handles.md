# Native Planning And Stats Branch Summary

This branch completed the native grouped-planning and stats-normalization work
that was split out from the Rust rewrite audit.

## Completed

- Added native grouped per-phenotype alignment planning.
- Switched grouped per-phenotype pipelines to consume native-planned groups.
- Exposed grouped alignment through `_core` and `_core.pyi`.
- Added stats-aware high-frequency normalization for variant-major linear
  kernels.
- Kept matrix-derived fallback behavior when native stats are absent.
- Added Rust, PyO3, and Python pipeline coverage for grouped alignment.
- Evaluated chunk-handle plumbing. No public handle API was added because the
  current PyO3 writer path already builds `NativeChunkHandle` from `Arc`
  metadata/stat wrappers without cloning column vectors.

## Remaining Follow-Up

1. Prediction planning metadata.
   - Move prediction alignment metadata closer to native grouped planning.
   - Keep Python as the execution orchestrator, but let Rust return enough
     metadata to make phenotype/covariate/sample/prediction alignment contracts
     explicit.

2. Row-major quarantine.
   - Keep production association paths variant-major.
   - Treat row-major delivery as legacy/test-only unless a measured workload
     needs it.

3. Telemetry sink ownership.
   - Consider moving the physical telemetry writer queue to Rust so Python and
     Rust events share one queue and file ownership policy.

4. Compatibility text output.
   - Add a typed Rust REGENIE TSV writer only if drop-in REGENIE-compatible
     output becomes a product requirement.

5. Benchmark-only SIMD override.
   - Add `auto|scalar|avx2` dispatch control only for reproducibility and
     benchmarking, not as normal user-facing tuning.
