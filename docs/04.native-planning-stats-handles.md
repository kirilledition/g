# Native Planning, Stats, And Chunk-Handle Rewrite

This branch implements four performance-oriented rewrites selected from the
Rust parts audit, excluding the Rust score-only backend and direct GPU
unpacking work.

## Goals

1. Group phenotypes by identical sample, covariate, and prediction alignment so
   per-phenotype semantics do not require repeated BGEN passes.
2. Use Rust-computed genotype statistics in JAX kernels to remove redundant
   device reductions.
3. Consolidate phenotype/covariate alignment around one native multi-trait
   planning pass instead of repeated single-trait alignment.
4. Carry native chunk metadata/statistics through writer paths without
   unnecessary Python/Rust metadata cloning.

## Implementation Order

1. Native stats in JAX kernels.
   - Add a stats-aware high-frequency normalization helper for variant-major
     linear score kernels.
   - Preserve existing matrix-derived fallback behavior.
   - Validate parity between stats-backed and matrix-backed kernels.

2. Chunk-handle plumbing.
   - Reuse the existing Rust `NativeChunkHandle` internals.
   - Expose handle-first PyO3 write paths only where they remove real metadata
     or stat cycling.
   - Keep compatibility methods available for tests and older call sites until
     all production callbacks are migrated.

3. Native grouped alignment planning.
   - Read phenotype and covariate tables once for grouped per-phenotype runs.
   - Build per-trait complete sample sets from native masks.
   - Group traits with identical sample indices and covariate matrix values.
   - Return grouped run inputs to Python without changing complete-case
     semantics.

4. Integration and cleanup.
   - Move production grouped per-phenotype pipelines to the native group plan.
   - Keep fallback alignment APIs while coverage is expanded.
   - Update type stubs and tests with the new native interfaces.

## Branch Status

- Native stats in linear JAX kernels: implemented. Variant-major linear
  normalization now uses native dosage sums and observation counts when they are
  available.
- Native grouped alignment planning: implemented for grouped per-phenotype
  pipelines. Rust reads requested phenotype columns and covariates once, builds
  per-trait complete sample sets, and returns compatible phenotype groups to
  Python.
- Chunk-handle plumbing: evaluated. The current PyO3 writer path already builds
  `NativeChunkHandle` from `Arc` metadata/stat wrappers without cloning column
  vectors. This branch keeps that path and avoids adding a redundant public
  handle API until callback delivery itself is proven hot.
