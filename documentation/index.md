# Documentation Directory

This page exists as the published site entry point. The documentation source is
split by audience:

- [User Guide](public/index.md) is the starting point for installing,
  configuring, and running `g`.
- [Development](development/index.md) is for maintainers and contributors.
- [Scratchpad](scratchpad/index.md) preserves internal work products and
  historical notes created during development.

User-facing product guidance belongs in `documentation/public/`. Development-team
documentation belongs in `documentation/development/`. Internal notes, review results,
profiling summaries, and other work artifacts belong in `documentation/scratchpad/`.
